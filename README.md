# Spatial profiling reveals functional heterogeneity of tertiary lymphoid structures in pulmonary sarcomatoid carcinoma

This repository contains processed datasets and source data generated and analyzed in the study:

**"Spatial profiling reveals functional heterogeneity of tertiary lymphoid structures in pulmonary sarcomatoid carcinoma"**

This study used Xenium spatial transcriptomics, multiplex immunofluorescence (mIF), and external single-cell RNA-seq analysis to characterize functional heterogeneity of tertiary lymphoid structures (TLSs) in pulmonary sarcomatoid carcinoma (PSC).

The datasets provided here correspond to the analyses and figures presented in the manuscript.

---

## Repository contents

### 1. TLS spatial annotation and boundary analysis

Files related to TLS localization, spatial boundary definition, and TLS-associated spatial analyses:

- **3A_re_TLS_boundary.csv**  
  Spatial annotation information related to TLS boundary identification.

- **TLS1_polygon.csv**  
  Spatial polygon coordinates defining TLS1-associated regions.

- **TLS2_polygon.csv**  
  Spatial polygon coordinates defining TLS2-associated regions.

- **total_distance_Polygon.csv**  
  Spatial distance measurements based on TLS boundary-defined regions.

- **S3B_TLS1_re_TLS2_TLS_boundaries_up-down.csv**  
  Comparative spatial analysis between TLS1- and TLS2-associated regions.

---

### 2. Cell composition and transcriptomic analysis

Files containing processed transcriptomic and cell-type-related quantitative results:

- **3_celltype_up_down.csv**  
  Cell-type comparison results associated with TLS1 and TLS2 states.

- **gene_in_celltype.csv**  
  Gene expression summaries across annotated cell populations.

- **B_plasma.csv**  
  B-cell and plasma-cell-related analysis results.

---

### 3. Functional enrichment analysis

- **GO_list.csv**  
  Gene ontology (GO) enrichment analysis results associated with TLS-state comparison.

---

### 4. Cell–cell communication analysis

- **Supplementary_Data_3_CellChat_ligand_receptor_pairs**  

  Ligand–receptor interaction results generated by CellChat analysis, corresponding to the inferred cell–cell communication analysis in the manuscript.

---

### 5. Multiplex immunofluorescence validation (Figure 5)

- **Supplementary_Data_1_Figure5_mIF_ROI_level_source_data.xlsx**

  ROI-level quantitative source data used for multiplex immunofluorescence statistical analyses in Figure 5.

  The dataset contains:
  - specimen/ROI identifiers
  - TLS-state classification
  - quantitative mIF measurements used for statistical comparison between TLS1-like and TLS2-like regions

---

### 6. External single-cell RNA-seq analysis (Figure 6)

- **Supplementary_Data_2_Figure6_GSE131907_TLS2**

  Sample-level TLS2 scores, immune-cell proportions, and statistical summaries used for external validation analysis based on the public LUAD single-cell RNA-seq dataset GSE131907.

---

## Data availability

The datasets deposited in this repository include processed quantitative data and figure-associated source data generated and analyzed in this study.

Raw Xenium sequencing output files, raw multiplex immunofluorescence whole-slide image files, and complete HALO project files are not included because of file-size limitations, institutional data-governance requirements, and patient privacy considerations.

The external single-cell RNA-seq dataset used in this study is publicly available through GEO accession number **GSE131907**.
